# Olist EC Sales Dashboard

## 概要

ブラジルECマーケットプレイス「Olist」の公開データを用いて、Power BIによるダッシュボードを作成しました。

売上・レビュー・地域・商品の4つの視点からECデータを分析し、SQLでデータ加工を行ったうえでPower BIによる可視化を実施しています。

---

## 使用技術

- Power BI
- PostgreSQL
- SQL
- Olist Brazilian E-Commerce Public Dataset

---

## データセット

使用した主なテーブル

- customers
- orders
- order_items
- order_reviews
- products
- geolocation

---

## SQLで実施した内容

- テーブル結合（JOIN）
- 売上計算
- 配送日数の算出
- 分析用VIEWの作成
- 地図表示用VIEWの作成
- レビュー分析用VIEWの作成

---

## ダッシュボード構成

### ① 売上分析

- 総売上
- 平均注文額
- 売上推移
- カテゴリ別売上
- 支払方法別売上

### ② レビュー分析

- 平均レビュー評価
- レビュー評価の分布
- 配送日数とレビュー評価の関係

### ③ 地域分析

- ブラジル国内の売上マップ
- 州別売上ランキング

### ④ 商品分析

- 平均商品価格
- 注文数上位カテゴリ
- 平均価格が高いカテゴリ

---

## 工夫した点

- SQLで分析用VIEWを作成し、Power BIでは分析に集中できる構成とした
- 緯度・経度データを利用し、ブラジル国内の売上分布を地図上で可視化した
- 配送日数とレビュー評価の関係を分析できるダッシュボードを作成した
- **英語のカテゴリ名や項目名を日本語へ変更し、日本語でも理解しやすいダッシュボードにした**
